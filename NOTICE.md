# Notice and credits

Pointdex is a fan project. It is licensed under the MIT license in [LICENSE](LICENSE), which is inherited from the firmware it builds on.

## Code

- [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader) (MIT): the firmware and interface this builds on, version 2.0.0.
- [padge01/xteink-pokemon-game](https://github.com/padge01/xteink-pokemon-game) (MIT): the original reading-powered Pokémon companion and the idea behind it.
- [thebitsworld/xteink-pokemon-game](https://github.com/thebitsworld/xteink-pokemon-game) (MIT): the battle system, trainers, gyms, items, moves and extra save formats that `main` is built from.
- [CrossInk](https://github.com/uxjulia/CrossInk) (MIT): the CrossPoint fork that both Pokémon projects are based on, and the original Time Left idea.
- [FreeInk SDK](https://github.com/Free-Ink/freeink-sdk): the hardware drivers and UI components used by CrossPoint.

The Pokémon game code in this repository was ported from the two Pokémon projects above and adapted to CrossPoint 2.0.0. The original authors keep their copyright.

## Art and data

No Pokémon artwork is stored in this repository. The art pack the game uses comes from the xteink-pokemon-game releases, which credit its sources, among them PokeAPI Sprites, PokéSprite and the pret/pokered disassembly. See the [rights and attribution file](https://github.com/thebitsworld/xteink-pokemon-game/blob/main/RIGHTS_AND_ATTRIBUTION.md) in that project for the full list.

The species, move, item, learnset, stat and gym tables under `scripts/data` are game data for the original 151 Pokémon.
